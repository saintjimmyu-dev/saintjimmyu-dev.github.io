Webhook Simulator

Two-service webhook delivery system with retry logic

Live Demo Source Code

Architecture

Client | [ EC2 Instance ] | +-----------+ | Nginx | | Reverse | | Proxy | +-----------+ / | \ / | \ /api/* / /receiver/* | Dashboard | v (/) v +-----------+ +-----------+ | Service A | | Service B | |-----------| |-----------| | Dispatcher| --> | Receiver | | HMAC- |webhook| ~20% fail | | SHA256 | | Groq LLM | | signing | | analysis | +-----------+ +-----------+ | Retry backoff 1s -> 2s -> 4s

Components

A

Service A — Dispatcher

Sends webhook payloads with HMAC-SHA256 signatures. Implements exponential retry backoff on delivery failures.

B

Service B — Receiver

Receives and verifies webhooks. Simulates ~20% random failures. Uses Groq LLM for payload analysis.

◉

Dashboard

Real-time metrics and delivery status. Monitor webhook attempts, successes, failures, and retry history.

⚙

Infrastructure

Provisioned with Terraform on AWS EC2. Nginx reverse proxy, Docker containers, CI/CD via GitHub Actions.
